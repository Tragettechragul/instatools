# Module 2 — Research inside Instagram

Read-only. Never follow, like or save while researching. Output: `instagram-data/research/YYYY-MM-DD-competitors.md` from `templates/competitors.md`.

## Finding accounts
1. Use Instagram's own search (the search panel, not Google). Search terms, UK first:
   `IT support London`, `IT support UK`, `cyber security UK`, `PC build UK`, `custom PC London`, `data recovery UK`, `data recovery London`, `computer repair London`, `tech repair UK`, then the same without location.
   Hashtag pages too: `#itsupport`, `#cybersecurity`, `#pcbuild`, `#datarecovery`, `#techrepair`, `#londonbusiness`.
2. Shortlist 5–10 accounts that are (a) active in the last 30 days, (b) clearly in this niche, (c) getting engagement that is high **for their follower count** — a 3K account averaging 300 likes beats a 200K account averaging 500. Prefer a mix: 2–3 UK local businesses, 2–3 UK IT/cyber creators, 1–2 larger global accounts as a ceiling reference.
3. If fewer than 5 good accounts exist, say so — don't pad with irrelevant ones.

## Per account
- Handle, URL, follower count, bio text (verbatim), link in bio, location if shown.
- **Posting frequency:** dates of the last ~12 posts → posts per week.
- **Format mix:** count of Reels / carousels / images in those ~12.
- **Top 3 posts by engagement** among those ~12 (likes + comments; views for Reels; saves/shares are `PRIVATE`). Record each post URL, format, date, numbers.
- **Full caption text** of each top post, verbatim.
- **Caption structure** for each: hook (first line, before "more"), body pattern (list / story / steps / question), CTA (exact wording), hashtag count and placement (end / first comment / inline), emoji count, total character length.
- **Audio on top Reels:** audio name, original vs licensed, and the use count shown on the audio page. Trend status: only report "rising" / "peaked" if Instagram visibly shows it; otherwise "trend not visible on web — N reels use this audio".

## Report (end of file)
- Formats and hooks working for others that the user isn't using (compare against module 1 data if it exists in `instagram-data/insights/`).
- 3–5 concrete things to try, each tied to an example post URL.
- What NOT to copy (trend-bait, misleading claims) given the professional tone in `profile.md`.
