# Module 4 — Caption research

Read-only. Output: `instagram-data/captions/YYYY-MM-DD-analysis.md` from `templates/caption-analysis.md`.

## Sources
1. The user's top posts — reuse `instagram-data/insights/*-posts.csv` if a recent one exists; otherwise collect via module 1, step 2.
2. Competitor top posts — reuse `instagram-data/research/*-competitors.md` if recent; otherwise run module 2 first.
Aim for at least 10 of the user's posts and 15 competitor posts. State the actual counts.

## Measure for each caption
- Character count and word count
- Hook: text of the first line, and whether it fits before the "… more" cut (~125 characters on feed)
- Body pattern: list / steps / story / myth-vs-fact / question / single statement
- Emoji count and position (hook / body / CTA / none)
- Hashtag count and placement (end of caption / first comment / inline)
- CTA: exact phrasing and type (save, share, comment keyword, follow, DM, link in bio, book/contact)
- Line breaks / paragraphs

## Analysis
- Averages and medians for the above, split: user vs competitors, and top-third vs bottom-third by engagement.
- What top performers do differently, in plain English, with example captions quoted.
- Be explicit when the sample is too small to call a pattern.

## Deliver: 5 caption templates
Each template must be built from a pattern actually seen in the data (cite the example post URL), fit the tone in `profile.md`, and include:
- the structure with blanks (`[HOOK: …]`, `[STEP 1]` …)
- target length
- hashtag count + placement
- CTA wording options
- one filled-in example on one of the user's content pillars, using only claims allowed by `profile.md`
